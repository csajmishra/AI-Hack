# AI-Hack: Your Azure AI Workshop

Welcome! Over four virtual sessions, you will build your own C# AI solution: start with an agent, ground it in company knowledge, add specialist agents, then deploy and integrate it through Azure API Management AI Gateway.

## Start here

1. Read the [participant guide](event-plan/README.md).
2. Complete the [setup checklist](event-plan/setup.md).
3. Choose customer support, HR helpdesk, or order processing as your scenario.
4. Follow the daily challenges and prepare your final demo.

| Day | What you will build |
|---|---|
| [Day 1](event-plan/day-1.md) | An end-to-end agent using Azure AI Agent Service |
| [Day 2](event-plan/day-2.md) | A grounded agent with advanced RAG and citations |
| [Day 3](event-plan/day-3.md) | A team of specialist agents |
| [Day 4](event-plan/day-4.md) | A deployed pilot with AI Gateway authentication, throttling, model-token controls, and final showcase |

**Audience:** 16 individual participants with beginner C# skills; no previous agent experience required. Use VS Code and GitHub Copilot, with one Azure subscription per participant.

**Repository status:** participant guides and challenge outlines only. Application projects, datasets, deployment templates, helper scripts, and checkpoint branches mentioned in the exercises are not included yet. Use the starter-kit link and tested SDK versions shared in the event announcement; do not run application commands in this documentation-only repository. Code snippets are illustrative.

Use synthetic data only. Never commit Azure credentials, connection strings, or personal/customer information.
